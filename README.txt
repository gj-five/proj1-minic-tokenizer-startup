# MiniC Tokenizer Startup

This is a simple guide to help you compile and run the MiniC tokenizer program in the SUN lab.

## Instructions

1. Open your terminal.

2. Navigate to the source code directory of the project by using the `cd` command. For example:

```shell
cd /home/dqp5476/Desktop/projl-minic-tokenizer-startup/src

3. Compile the Java source files using the javac command. You can use the wildcard *.java to compile all Java files in the directory:
	javac *.java

4. Once the compilation is successful, you can execute the MiniC tokenizer program by running the following command, replacing    test1.minc with the MiniC source file you want to tokenize:

	java Program test1.minc
